# 1. Make sure Docker Engine is running
sudo systemctl start docker

# 2. Use the normal Docker Engine context
docker context use default

# 3. Go to Judge0
cd ~/Downloads/judge0-v1.13.1

# 4. Start Judge0
docker compose up -d

# 5. Check containers
docker ps


| What you want                         | Command                  |
| ------------------------------------- | ------------------------ |
| Stop containers                       | `docker compose stop`    |
| Start stopped containers              | `docker compose start`   |
| Stop + delete containers              | `docker compose down`    |
| Start/recreate containers             | `docker compose up -d`   |
| Stop + delete containers + volumes ⚠️ | `docker compose down -v` |
